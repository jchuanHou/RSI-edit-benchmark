# BrushNet 与 PowerPaint 实验结果分析

- 文档日期：2026 年 10 月 8 日。
- 实验范围：`brushnet_sd15_random_s42` 与 `powerpaint_v1_unipc_s42` 两次正式全量运行。
- 数据规模：同一组 1550 个图像、掩码、提示词样本。
- 时间口径：本文运行时间全部为北京时间（UTC+8）；原始状态文件使用 UTC。
- 分析方式：读取正式配置、汇总结果、逐样本指标、数据清单和评估实现，并重新计算配对统计；未重新运行模型，未修改实验产物，未进行人工图像质量评审。

## 一、结论摘要

**两组实验均完整成功。当前证据更支持 BrushNet 在背景像素误差与背景感知距离方面表现较好，但不足以认定其整体编辑质量优于 PowerPaint。两者文本一致性接近，背景结构相似性存在明显的均值与多数样本结论分歧。**

1. **完成情况可靠**：两者均完成 1550/1550 个样本的推理和评估，任务状态为 `complete`、退出码为 `0`，推理失败数为 0，评估没有缺失样本或指标错误。
2. **文本一致性没有明确的全面胜者**：PowerPaint 的全局 CLIP 均值高 0.108330；BrushNet 的局部 CLIP 均值高 0.113634。但逐样本比较中，PowerPaint 的全局、局部 CLIP 分别在 51.35%、51.55% 的样本上更高，差距接近均衡。不能把均值略高理解为语义编辑能力显著更好。
3. **BrushNet 的背景 MAE、背景 LPIPS 优势较一致**：相对 PowerPaint，均值分别降低 11.96%、9.97%；逐样本数值占优比例分别为 65.03%、64.13%。这支持其在当前设置下背景改动通常较小。
4. **SSIM 必须单独解读**：BrushNet 的背景 SSIM 均值高 0.002205，但 PowerPaint 在 71.48% 的样本上更高。BrushNet 的均值优势受到部分大差值样本影响，不能概括为“多数图像的背景结构保留更好”。
5. **更接近原图不等于编辑更成功**：BrushNet 的全图、掩码内、边界 LPIPS 及 FWD 均更低，但参考对象是原图，不是编辑后的目标真值。较低距离既可能意味着更好保留，也可能意味着修改不足，必须结合文本与视觉评审判断。
6. **耗时只作本次运行记录**：BrushNet 总耗时约 9 小时 4 分，PowerPaint 约 7 小时 45 分。两者曾共享同一张 T4，启动时间和资源竞争不同，不能据此得出独占硬件上的模型速度排名。

### 2.2 不能忽略的方法差异

| 项目 | BrushNet | PowerPaint |
|---|---|---|
| 方法 | `BrushNet-SD15-random-mask` | `PowerPaint-v1-text-guided` |
| 基础模型 | `stable-diffusion-v1-5/stable-diffusion-v1-5`，普通 SD1.5 基础模型 | `stable-diffusion-v1-5/stable-diffusion-inpainting`，9 通道 inpainting 基础模型 |
| 方法权重 | `Sanster/brushnet_random_mask`，配置标注为社区 FP16 分发版本 | `JunhaoZhuang/PowerPaint-v1`，配置标注为官方原始 v1，不是基于 BrushNet 的 v2 |
| 正提示词 | 直接使用数据集提示词 | 数据集提示词加 `P_obj`，对应 10 个学习向量 |
| 负提示词 | 空字符串 | `, worst quality, low quality, normal quality, bad quality, blurry P_obj` |
| 方法特有参数 | `brushnet_conditioning_scale=1.0` | `tradeoff=1.0` |
| 掩码输入方式 | 编辑区 RGB 置黑后作为条件图输入 | 提供原 RGB，由 pipeline 在归一化后实施遮蔽 |
| `diffusers` | `0.27.0.dev0` | `0.27.0` |
| 显存限制 | 配置未记录与 PowerPaint 相同的比例限制 | 推理配置 `memory_fraction=0.4`，评估亦包含显存保护 |

**比较边界**：这是两套具体模型与适配配置的系统级对照，不是仅改变网络结构的严格消融实验。提示词策略、基础模型和实现差异均可能影响结果；结论应绑定到当前权重与配置，不能泛化到所有 BrushNet/PowerPaint 版本。`random-mask` 是所用 BrushNet 权重的标识，不能据此断言本数据集掩码是本次随机生成的。

### 2.3 数据集组成与清单注意事项

- 共 250 条不同提示词，每条关联 1–16 个样本。因此 1550 个样本不等于 1550 条彼此不同的指令。
- 掩码面积占比最小 3.52%、均值 15.43%、最大 64.84%；没有空掩码、全图掩码或非二值掩码记录。
- 数据清单明确以 `prompts.json` 和实际图像/掩码文件为准。旧 `dataset_info.json` 与实际集合存在差异：有 7 个仅旧信息文件列出的文件，另有 7 个仅实际集合包含的文件。
- 这不是本次两方法之间的数据不一致或输出缺失，但复现实验时必须使用当前核实后的清单，不能只凭旧信息文件或目录名称决定样本集合。

## 四、完整指标对比

令 B 表示 BrushNet，P 表示 PowerPaint；差值统一为 B − P。所有指标覆盖 1550 个样本。均值后的“±”是样本间指标值的总体标准差，不是置信区间或多随机种子波动；FWD 是集合级指标，不提供逐图标准差。

## 五、逐样本配对分析：均值之外的结果

### 5.1 配对方法与数值占优比例

以相同样本 ID 对齐两个逐样本结果文件，得到 1550 对唯一且完整的记录。对每一指标计算 B − P 的中位数，并按第四节的数值方向计数；以下指标均无相等值。

对于原图距离指标，“占优”仅指距离更低，不是人工判定的编辑成功。FWD 没有逐样本标量，不计算逐样本占优比例。

| 指标 | 配对差值中位数 B − P | B 数值占优：数量（比例） | P 数值占优比例 |
|---|---:|---:|---:|
| 全局 CLIP | -0.030287 | 754（48.65%） | 51.35% |
| 局部 CLIP | -0.063241 | 751（48.45%） | 51.55% |
| 背景 MAE | -0.000593 | 1008（65.03%） | 34.97% |
| 背景 PSNR | +0.128101 | 929（59.94%） | 40.06% |
| 背景 SSIM | -0.002465 | 442（28.52%） | 71.48% |
| 边界 MAE | -0.000411 | 814（52.52%） | 47.48% |
| 全图 LPIPS | -0.010883 | 1040（67.10%） | 32.90% |
| 背景 LPIPS | -0.005209 | 994（64.13%） | 35.87% |

| 边界 LPIPS | -0.025544 | 985（63.55%） | 36.45% |

**解读：**

- 背景 MAE 和背景 LPIPS 的均值、中位配对差值、多数样本方向一致，因而比“只看一个均值”更能支持 BrushNet 在这两个背景保留指标上的优势。
- 局部 CLIP 的 BrushNet 均值更高，但多数样本及配对差值中位数偏向 PowerPaint，说明差异分布并不对称，不能称为普遍优势。
- 背景 SSIM 的分歧尤其明显：多数样本偏向 PowerPaint，少数较大差值可将总体均值拉向 BrushNet。不同指标测量的是不同误差特征，不能因为 MAE 更低就推定 SSIM 也在多数样本上更高。

## 六、指标解释与结论边界

### 6.1 文本一致性

- CLIP 分数是归一化图像/文本特征点积乘以 100，不是成功概率或准确率。
- 局部 CLIP 是把生成图掩码外像素置黑后送入 CLIP，**不是裁剪掩码包围框**。掩码大小、形状和黑色区域可能影响分数。
- 即使两者评估使用相同的数据集文本，推理时的提示词构造仍有差异。本次小幅 CLIP 差异不足以证明方法的普遍语义能力差异。

### 6.2 背景保留与编辑区域

- 背景 MAE、PSNR、SSIM 和背景 LPIPS 对“非编辑区域是否尽量保持原图”有参考价值。MAE 的图像像素范围为 [0,1]；PSNR 为逐样本计算后取均值。
- 区域 LPIPS 是在完整图像的空间感知距离图上按掩码取均值，特征感受野可能跨越区域边界；背景 SSIM 的窗口也可能跨边界。因此它们不是完全隔离的背景或前景测量。
- 原始图像从 224 × 224 放大至工作尺寸，再将生成图降至 256 × 256；评估参考图按 BILINEAR 缩放。结果反映整条处理链路，而非仅模型内部某一步。
- 掩码内更低的原图 LPIPS 不能区分“成功编辑但结构保留”和“改动不足”；更高也不能区分“合理的新内容”和“内容失真”。

### 6.3 边界与分布指标

- 边界带按掩码膨胀减腐蚀构造，形态学参数宽度为输出图像 3 像素。边界 MAE/LPIPS 比较的是原图，不直接度量接缝自然度。
- FWD 使用 `pytorchfwd`、Haar 小波、最大层级 4、`log_scale=false`、`resize=256`，比较的是生成集合与原图集合。
- BrushNet 的 FWD 更低支持“在这一度量下整体分布更接近原图”，不等同于文本任务成功率更高，也不能与其他分辨率、实现或数据集上的 FWD 数值直接横向比较。

### 6.4 当前不能得出的结论

本次仅一个随机种子，没有多次独立运行、正式配对置信区间或多重比较校正；同一提示词下样本也可能相关。因此本文提供描述性分析，不使用“统计显著优于”作为结论。

本报告也没有人工盲评、目标编辑真值或针对目标对象的独立检测证据，不能据此确定真实性、空间正确性、对象数量正确性或最终可用性。不能简单按“11 项指标赢了多少项”给出综合冠军，因为多个指标高度相关，且指标方向与任务目标并不完全一致。

## 七、建议与可直接引用的总结

### 7.1 当前选型建议

- 若优先减少背景像素误差和背景感知改动，**可优先将当前 BrushNet 配置作为后续验证基线**；依据是背景 MAE、LPIPS 的全量均值与多数样本方向一致。
- 若关注多数样本的背景结构相似性，**应保留 PowerPaint 对照**，因为它的背景 SSIM 逐样本占优比例更高，同时需要排查其低分尾部案例。
- 若优先确保按文本完成目标编辑，**暂不选定绝对胜者**；目前 CLIP 差距小，且局部均值与多数样本方向不一致，需结合人工评审或任务专用度量。

### 7.2 后续工作优先级

1. **先做分层视觉盲评**：同时展示原图、掩码、提示词及两个输出；随机抽取不同面积组的样本，并额外加入 SSIM 极端差值样本。随机样本与定向问题案例分别统计，评价文本满足、背景保留、边界自然度与整体可用性。
2. **补齐多种子重复**：沿用同一数据清单和固定协议，增加多个 seed；同时报告跨种子波动和配对差值。置信区间应考虑按提示词或数据来源聚类，而非直接假设所有图像独立。
3. **按方法与处理链路区分消融**：在方法允许的范围内检查负提示词、工作分辨率和背景回贴的影响。回贴可能机械改善背景指标，若实验需比较，应作为单独处理条件报告，不能与当前“无回贴”结果混合。
4. **重新测公平效率**：在独占同型号 GPU 上使用相同样本、预热、测量窗口和精度，分别记录推理延迟分位数、吞吐与峰值显存；不复用本次并行墙钟时间作公平性能排名。
5. **补充任务成功度量**：结合真实任务定义增加对象、位置或其他可验证的成功条件；不能仅靠提高相对原图相似度推动优化。

### 7.3 可引用总结

> 在同一组 1550 个样本、50 步推理、固定 seed=42、512 像素工作尺寸及 256 像素输出的实验中，BrushNet 与 PowerPaint 均完成全量推理和评估。BrushNet 的背景 MAE 与背景 LPIPS 相对 PowerPaint 分别降低 11.96% 和 9.97%，且在约 65.03% 和 64.13% 的样本上取得更低数值，表明当前配置下其背景误差控制具有一定优势。两者的全局与局部 CLIP 均值差异较小，局部 CLIP 与背景 SSIM 还存在均值和多数样本方向不一致的现象。由于参考图为原图而非编辑真值，且实验仅覆盖单一随机种子，这些结果不足以证明某一方法具有全面更优的语义编辑质量，仍需多种子与视觉评审进一步验证。

### 派生统计口径

- 全量均值与标准差取正式 `eval_results.json`；逐样本文件重算的均值与报告一致，误差小于 1e-10。
- 差值统一取 B − P；距离下降百分比按 (P − B) / P × 100% 计算。
- 配对中位数是逐 ID 差值的中位数，不是两组中位数相减；占优比例分母为全部 1550 对样本，按原始未舍入值比较。
- 掩码分组依据数据清单的 `mask_fraction`，分别为 <0.10、≥0.10 且 <0.25、≥0.25，未依据结果改变分组边界。
- 提示词宏平均先按完整提示词文本精确分组，组内对图像平均，再对 250 组等权平均。
- SSIM 截尾检查对配对差值排序后分别删除两端 77 对，仅作为尾部敏感性描述；正式指标始终使用完整 1550 个样本。
