## 2. 代码来源：定位上游基线

### 2.1 方法

`src/diffusers/__init__.py` 中的版本号是 `0.29.0.dev0`，说明这是 diffusers v0.28 和 v0.29 之间的某个**主干开发版本**。为了准确区分“作者改动”和“上游原有代码”，我做了以下工作：

1. 对 diffusers 官方仓库做 blobless 克隆（只取提交和树对象）；
2. 取 2024-04-20 ~ 2024-06-20 之间主干上的 234 个提交；
3. 对每个提交，用 `git ls-tree -r` 取 `src/diffusers` 下所有文件的 blob 哈希，与 Text2Earth 仓库中对应文件的 blob 哈希比较，统计不一致的文件数；
4. 取不一致数最少的提交作为基线。

### 2.2 结果

| 候选上游提交 | 日期 | 不一致文件数 |
|---|---|---:|
| `0d68ddf` | 2024-06-07 | **12** |
| `83bc6c9` | 2024-06-08 | **12** |
| `4e0984d` | 2024-06-10 | **12** |
| `7d88711` | 2024-06-07 | 13 |
| `1d9a6a8` | 2024-06-10 | 14 |

三个提交并列最少（它们之间的差异不涉及 `src/diffusers`），所以基线就是 **diffusers 主干 2024-06-07 前后的版本**，早于 v0.29.0 正式发布（v0.29.0 引入了 SD3，这个快照里没有 `transformer_sd3.py`、`stable_diffusion_3/`、`scheduling_flow_match_euler_discrete.py`）。

412 个文件中，**400 个与上游完全一致**，只有 12 个不同。

## 4. 与 HuggingFace Hub 上 custom pipeline 的关系

HF 模型仓库 `lcybuaa/Text2Earth` 根目录下也有一份 `pipeline_text2earth_diffusion.py`（编辑版仓库中是 `pipeline_text2earth_diffusion_inpaint.py`）。逐行比较后：

- 逻辑与本仓库中的版本**完全相同**；
- 唯一区别是 import 方式：Hub 版使用绝对导入 `from diffusers... import ...`，本仓库版使用包内相对导入 `from ...xxx import ...`；另有一处文档字符串示例的模型 ID 不同。

所以 README 中的两种用法本质上运行的是**同一份代码**：

| 用法 | 方式 | 需要安装本仓库吗 |
|---|---|:---:|
| Usage 1 | 官方 diffusers + `custom_pipeline="pipeline_text2earth_diffusion"`，从 Hub 下载并执行 pipeline 脚本 | ✗ |
| Usage 2 | `pip install -e ".[torch]"` 后直接 `from diffusers import Text2EarthDiffusionPipeline` | ✔ |

## 6. 安装与打包

### 6.1 `setup.py` 的关键事实

```python
setup(
    name="diffusers",              # ⚠ 包名仍然是 diffusers
    version="0.29.0.dev0",
    package_dir={"": "src"},
    packages=find_packages("src"),
    install_requires=[importlib_metadata, filelock, huggingface-hub>=0.23.2,
                      numpy, regex, requests, safetensors>=0.3.1, Pillow],
    extras_require={"torch": ["torch>=1.4", "accelerate>=0.29.3"], ...},
    ...
)
```

- `pip install -e ".[torch]"` 安装的包名是 **`diffusers`**，会**覆盖**当前环境中已安装的官方 diffusers；
- `transformers` **不在** `install_requires` 里（文本编码器和分词器需要它），必须另外安装（`transformers>=4.25.1`）；
- README 建议的 Python 版本是 3.9。

### 6.2 推荐安装方式（分析者建议）

```bash
python3 -m venv ~/venvs/text2earth && source ~/venvs/text2earth/bin/activate
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install "transformers>=4.25.1,<4.45" accelerate safetensors
cd /data/workspace/Text2Earth && pip install -e .
```

如果不想替换 diffusers，可以改用 Usage 1：安装官方 `diffusers==0.29.x`，再通过 `custom_pipeline` 加载。但这会从 Hub 下载并执行远程脚本，建议先审阅脚本内容（已确认与本仓库版本逻辑一致）。
